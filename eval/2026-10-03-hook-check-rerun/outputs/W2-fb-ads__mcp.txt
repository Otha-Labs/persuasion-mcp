**Check these before running:**
- **All three ads lack proof.** A copy-review tool flagged this in every draft. I left a bracket where a real student quote or result should go. I didn't make one up, and you shouldn't run them with an invented one. If you don't have testimonials yet, delete the bracket line.
- **Check the claims against the course.** All three say "set up once, then 2 hours a month." If setup takes much longer than 2 hours, say how long it takes so the claim stays honest. Variation 2 also only works if "three numbers" matches how the course actually teaches bookkeeping.
- **Variation 3 has a date in it.** "3 months left in 2026" is correct today (Oct 3). Update it each month or remove it once the ad is running in December.
- **How to test:** Run all three with the same image. Each one tests a different idea: Variation 1 says "you're already good at this," Variation 2 says "it's simpler than you think," and Variation 3 leans on the pain of tax season. The winner tells you which message to build the rest of your marketing on.
